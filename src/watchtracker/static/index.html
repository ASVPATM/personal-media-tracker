    Flexible import

    Bring in almost any existing media list ?

    The app directly previews UTF-8 CSV files and Letterboxd export ZIPs. If your list is a document, spreadsheet, text file, JSON, or an unusual export, you can first convert a copy to the small CSV format below.

    1. Decide whether your source contains ratings and identify its scale (for example, 5 stars, 10 points, or 100%).
    2. Optionally paste the prompt and a copy of your list into an AI model, or use the same column rules to format it yourself.
    3. Review the result, save it as a UTF-8 .csv file, then use Import to preview every change before committing.
    Copyable conversion prompt
    Convert my media list into a UTF-8 CSV for Personal Media Tracker.

Before converting it, ask me these two questions:
1. Does this source contain personal ratings?
2. If yes, what rating scale does it use?

Return only raw CSV, without Markdown fences or explanation. Use this exact header:
title,release_year,media_type,status,personal_rating,watched_date,view_count,tags,notes

Rules:
- Never invent a title, rating, date, view count, tag, note, or year.
- Use one row per title. Properly quote any field containing commas, quotes, or line breaks.
- media_type must be movie, tv, or anime. Use movie only when the source gives no clue.
- status must be watched, watching, plan_to_watch, dropped, or rewatching.
- personal_rating must be blank or 1–10 with at most one decimal. Convert 5-star ratings by multiplying by 2. Convert another scale only after I confirm it.
- watched_date must be blank or YYYY-MM-DD. Do not guess missing dates.
- view_count is the total number of viewings. Use 1 for a watched title only when the source confirms it was watched but gives no count.
- Separate multiple tags with |. Preserve private notes only if I explicitly include them.

    Privacy note: An AI service is optional and separate from this app. Uploading a list shares it with that provider, so remove private notes or use an offline model if that matters to you. Always review generated CSV; the app will show a preview and will not change your library until you commit it.

    Advanced rankings

    How technical scores work

    Your personal rating is always the anchor. PMT never silently replaces or rewrites it.

    The calculation at a glance
    Technical score=Personal rating+Rubric adjustment
    maximum ±0.75    +Comparison adjustment
    maximum ±0.75

    Work in progress.

    The final result is kept between 1 and 10. Evidence coverage reduces the rubric influence, while comparison reliability uses n ÷ (n + 8) so a few choices cannot move a title too far.

    Structured title evidence
    Your 1–5 answers about impact, distinctiveness, freshness, engagement, coherence, and staying power can make a small bounded adjustment. Half steps are available.
    Direct comparisons
    A bounded adaptive sample of nearby titles helps settle close ordering without exhaustive or repeated pairs. Uncertain choices are skipped.
    Evidence coverage
    Only remembered questions and completed comparisons determine how well supported the technical score is. “Not refined” means PMT has little or no advanced evidence for that title.
    Rewatches
    Stored rewatches remain useful context and future insight data, but never add automatic ranking points.
    Stable ordering
    When scores remain tied, PMT uses deterministic tie-breaking so the list does not jump around between refreshes.

    Technical rankings are an interpretation layer over your ratings—not an objective judgment about a title.

    Advanced ranking refinement

    How much would you like to refine?

    Your personal ratings remain unchanged. The process first calibrates close calls with comparisons, then records structured evidence for individual titles.

    Actual rewatch count is shown during reflection, but it never adds technical-ranking points automatically. You decide whether return value matters through an optional question.

    What is my PMT Server invitation link?

    It is a private, one-use link created by the separate PMT Server Beta application. It proves that the server owner invited you to create an account; merely finding a server never permits open registration.

    1. Finish setup in the standalone PMT Server application.
    2. From its People and invitations screen, create a regular-user invitation.
    3. Connect this device to the same Tailscale network and paste the complete invitation link into PMT.
    4. PMT verifies the server, opens account creation, and stores only a revocable device token in your operating-system credential vault.

    The loopback addresses 127.0.0.1 used by the private PMT Flow preview work only on the same computer and are not an address for another device.
